# Mülltermine Bergheim

Automatischer Kalenderabruf und live testbare Suchregeln für die Mülltonnen in Bergheim.

Nach der Installation die App starten und **Weboberfläche öffnen** wählen.
Die fachlichen Einstellungen werden dort gespeichert. Die normale Konfigurationsseite enthält die Protokollstufe.
